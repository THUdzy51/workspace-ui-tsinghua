# Wordbook sources

The dashboard stores local copies of the wordbooks so vocabulary study works offline.

- `ngsl.json`: NGSL 1.2, 2,809 entries. The NGSL Project describes NGSL as a 2,809-word core list and publishes its lists under Creative Commons. The JSON file was obtained from the public qwerty-learner dictionary collection.
- `academic.json`: 897-entry academic-English study collection from the public qwerty-learner dictionary collection.
- `ielts.json`: 2,644-entry IELTS practice collection from the public qwerty-learner dictionary collection. It is a practice collection, not an official IELTS-required list.

Data collection: https://github.com/zhghx/qwerty-learner (GPL-3.0)

NGSL Project: https://www.newgeneralservicelist.com/word-lists
